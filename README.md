# ML Model Project Portfolio

This repository collects small machine-learning notebooks and experiments that explore different Kaggle-style datasets. Each project folder is self-contained and typically includes exploratory data analysis, feature engineering, model training, and evaluation steps.

## Repository structure

- **`NLP Disaster tweets/`** – Natural language processing workflow for classifying whether tweets describe real disasters.
- **`Practice/`** – Miscellaneous experiments, scratch work, and utility notebooks used while learning new concepts.
- **`Sentiment Analysis/`** – Text-preprocessing and sentiment modeling exercises on short-form messages.
- **`Titanic Survival/`** – Classic classification baseline predicting passenger survival on the Titanic dataset.
- **`house-prices-advanced-regression-techniques/`** – Regression models for the Kaggle House Prices challenge, including feature engineering and model comparison.

## Getting started

1. Install project dependencies inside a virtual environment (e.g., `python -m venv .venv` and `pip install -r requirements.txt` if provided inside a project folder).
2. Open the notebooks in JupyterLab or Jupyter Notebook: `jupyter lab` (or `jupyter notebook`) from the repository root.
3. Run the notebooks cell by cell to reproduce the analyses.

Feel free to adapt these notebooks, try alternative models, or extend the analyses with additional features and evaluation metrics.
